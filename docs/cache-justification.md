# Обоснование выбора дополнительной функциональности

## Выбранная функция: Кэширование результатов проверок

1. **Экономия ресурсов внешнего API**
    - не перегружаем сервер NHTSA большим количеством запросов
    - Один VIN не меняется со временем
    - Повторные запросы того же VIN не нужны

2. **Улучшение производительности**
    - Запрос к NHTSA: ~1-2 секунды
    - Ответ из кэша: ~10 миллисекунд

3. **Лучший пользовательский опыт**
    - Пользователь видит мгновенный результат при повторной проверке
    - Нет задержек на ожидание внешнего API

## Реализация
- Использован Spring Cache с аннотацией `@Cacheable`
- Время жизни: 24 часа
- Локальный кэш в памяти приложения

## Результат
- Второй и последующие запросы того же VIN не обращаются к NHTSA
- Данные отображаются мгновенно
- Экономия вызовов внешнего API
